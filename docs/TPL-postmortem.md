# Postmortem: <incident title>

Blameless template. Copy it to `docs/postmortems/YYYY-MM-DD-<slug>.md` within five working days of an incident that touched a claimant, an approval, a send, or the evaluation gate.

## Table of Contents

- [Summary](#summary)
- [Impact](#impact)
- [Timeline](#timeline)
- [Root Cause](#root-cause)
- [What Went Well](#what-went-well)
- [What Was Hard](#what-was-hard)
- [Actions](#actions)

---

## Summary

Two or three sentences: what happened, how it was found, how it ended.

## Impact

Who and what was affected, for how long, measured: cases, emails, claimants, dollars, hours. Say what is unknown.

## Timeline

All times UTC. Detection, each decision and who made it, mitigation, resolution.

| Time | Event |
|---|---|
| | |

## Root Cause

The chain of causes down to the one that, fixed, prevents the whole class of incident. Name systems and decisions, never people. If an agent or model acted wrongly, name the guard that should have stopped it and why it did not.

## What Went Well

Detection, guards that held, people who helped.

## What Was Hard

Missing signals, unclear runbooks, slow tools.

## Actions

Each action fixes a cause, has one owner and a date, and is tracked as an issue. A test that reproduces the incident is the first action.

| Action | Owner | Due | Issue |
|---|---|---|---|
| | | | |
